要做的是什么？
1. 创建一个包含features的库，（跟添加依赖库时，可以指定features是一样的）
    - 添加[features]节点，并添加节点的内容
2. 创建多个features时，features的依赖传递问题， cargo tree

----
### 如何使用
3. features的测试
    - 本地测试代码开启feature： #[cfg(feature = "async")]
    - cargo test --features "json,async"
4. 使用方：
    - 本地使用：  
        1. cargo中配置项目自己的feature，
        2. 指定依赖的feature, feature_demo = { path = "../feature_demo", default-features = false, features = ["async"] }
        3. 代码中指定feature配置（且该feature为自己项目的feature），#[cfg(feature = "async")]
        4. 运行指定feature， cargo run --no-default-features --features json  等等
            cargo run --help 中 Feature Selection:部分内容
    - 库使用：
        - feature_demo = { version = "xxx", default-features = false, features = ["async"] }
