### ✅ `dbg!` 是 **Rust 语言**里的调试宏
#### 1. 基础作用
- 打印变量/表达式的值 + 源码位置（文件名、行号），**同时原样返回原值，不中断程序**
- 方便快速查看变量值、排查问题，只用于开发调试，不要留在正式生产代码

#### 2. 语法 & 例子
```rust
fn main() {
    let x = 10;
    // 使用 dbg!
    dbg!(x);
    dbg!(x * 2 + 3);
}
```
输出类似：
```
[src/main.rs:4:5] x = 10
[src/main.rs:5:5] x * 2 + 3 = 23
```

#### 3. 和普通 `println!` 的区别
- `println!`：只打印内容，**不返回值**，格式需要手动写
- `dbg!`：
    - 自动打印位置、表达式代码、值
    - 保留原值，可直接嵌入代码里使用
      ```rust
      let y = dbg!(x + 1); // 先打印，再把结果赋值给 y
      ```
    - 默认输出到 **stderr（标准错误流）**，不是普通 stdout
    - 支持任意可 Debug 的类型

#### 4. 关闭/注意事项
- `dbg!` 是编译存在的宏，不会自动在 release 模式下消失，上线前建议删掉
- 底层依赖类型实现 `Debug` trait，绝大多数 Rust 基础类型都自带实现

一句话总结：**Rust 专属调试宏，一键看变量值和代码行号，非常方便临时查值！**
