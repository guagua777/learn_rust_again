# 核心一句话分清两个概念
1. **类型 `str` 本身是「尺寸编译期未知」的 DST 类型**（类型层面无固定大小）
2. 字符串字面量 `"hello"` 只是**某一段具体、长度固定的字节数据**（实例层面长度固定）

二者完全不冲突，拆开讲清楚：

## 1. 先讲：为什么 `str` 叫「无固定大小类型（DST）」
类型的**尺寸**是编译器在编译时必须能算出占用多少内存。
- `u32`：永远4字节，固定尺寸；
- `[u8; 5]`：固定5个字节，固定尺寸；
- `str`：**单纯只看 `str` 这个类型，编译器不知道它有多长**。

`str` 代表「任意一段 UTF-8 字节序列」：
可以是 `"a"`（1字节）、`"abc"`（3字节）、`"很长一段中文"`（十几字节）。
不存在一个统一、固定的字节长度属于 `str` 类型本身，所以它是**动态尺寸类型 DST**。

### 关键证明：不能直接声明 `let x: str`
```rust
let s: str = "hello"; // 编译报错
```
编译器报错理由就是：`str` 无静态已知大小，无法直接分配在栈上。

## 2. 再看 `&str = "hello"` 是什么
`&str` 是**指向一段 `str` 的借用胖指针**，包含两块信息：
1. 字节起始地址
2. 这段 `str` 的字节长度

```rust
let s1: &str = "hello";
let s2: &str = "hello world";
```
- `s1` 指向一段长度5的 `str`；
- `s2` 指向一段长度11的 `str`；

变量 `s1`、`s2` 本身（胖指针）大小固定（两个 usize），但它们指向的底层 `str` 实体长度完全不固定。

### 类比数组切片 `[T]`，一模一样逻辑
- `[u8; 5]`：定长数组，类型自带固定长度；
- `[u8]`：切片本体 DST，长度不固定；
- `&[u8]`：切片引用，指向任意长度的 `[u8]`

```rust
let a: &[u8] = &[1,2,3];   // 底层 [u8] 长3
let b: &[u8] = &[1,2,3,4]; // 底层 [u8] 长4
```
不能因为 `a` 指向一段固定3字节数据，就说 `[u8]` 是定长类型；
同理，不能因为 `"hello"` 长度固定，就说 `str` 是定长类型。

## 3. 区分两个容易混淆的维度
### 维度1：类型层面（str）
- 代表任意 UTF-8 字节段
- 长度不绑定在类型上，编译期无法确定大小
- 描述：**动态长度、无固定尺寸**

### 维度2：具体实例层面（"hello"）
- 这是一段实实在在存在的字节数据
- 在编译时就能算出它占5字节，实例长度固定

### 你疑惑的点拆解
> `"hello"` 明明长度固定，为什么说 str 是动态长度？

答：
`"hello"` 只是**无数种长度的 str 实例之一**。`str` 这个类型可以承载任意长度文本，没有统一固定尺寸，所以归类为动态长度DST；
而字面量只是某一个确定长度的具体数据，二者不在同一层面。

## 4. 延伸：String 和 str 的对比辅助理解
- `String`：堆上存字节，栈上结构体存指针+长度+容量；**类型本身大小固定**，运行时内容长度可变；
- `str`：底层字节序列，**类型本身无固定大小**，内容只读不可变长，但可以是任意长度。

## 极简总结
1. `str` 是类型概念：能代表任意长短的UTF8文本，编译器无法预知它的尺寸 → 无固定大小DST；
2. `"hello"` 是一段具体数据：当前这个实例长度固定为5字节；
3. `&str` 是指针，用来“挂靠”不同长度的 str 片段，所以我们代码里只能用 `&str`。




# 结论先给你
`"hello"` 字符串字面量本体：**既不在栈，也不在堆，存在程序的只读常量段（.rodata）**
变量 `s1`（&str 胖指针）：**存在栈上**

## 1. 拆分两行看懂
```rust
let s1: &str = "hello";
```
分成两部分：
### ① `"hello"` 字面量数据本体
- 编译时直接写进二进制文件的只读数据段 `.rodata`
- 程序运行后映射到**只读内存**，生命周期 `'static`，全程不释放、不可修改
- 不属于栈/堆，是独立的静态常量内存
- 长度编译期就确定：`h e l l o` 5 个 u8 字节

### ② 变量 `s1`
`s1` 的类型是 `&'static str`，是**胖指针**：
- 栈上分配两个 usize：
  1. 指向 `.rodata` 里 `"hello"` 首字节的地址
  2. 字节长度 5
- s1 本身在栈，大小固定（64位系统占 16 字节）

## 2. 和 String 做对比，分清栈/堆/常量段
```rust
// 情况1：字面量 &'static str
let s1 = "hello";
// "hello" → .rodata 常量段
// s1胖指针 → 栈

// 情况2：String
let s2 = String::from("hello");
// "hello" 先拷贝一份到堆内存（可修改）
// s2 栈上结构体：堆指针 + len + cap
```

## 3. 补充一个容易混淆的点
如果从 String 切片得到 &str：
```rust
let s = String::from("abc"); // 数据在堆
let slice = &s[..]; // &str
```
这里 `slice` 胖指针依然在栈，但它指向的底层字节是**堆内存**，不是常量段。

## 一句话总结
`let s1: &str = "hello";`
- `"hello"` 文本：静态只读常量段（.rodata）
- 引用变量 `s1`：栈上胖指针
- 全程**不涉及堆分配**。
